# WebAnyOne Form Field Duplicator 1.0.0

Première version du plugin open source WebAnyOne pour dupliquer une question et ses descendants conditionnels dans l’éditeur de formulaire Mautic.

## Fonctionnalités

- Duplication dans le brouillon, pour les formulaires autonomes et de campagne, neufs ou existants.
- Champs Mautic natifs indépendants : nouveaux alias et identifiants, conditions internes remappées, choix et paramètres conservés.
- Retrait des associations contact/entreprise ; les listes synchronisées deviennent des choix locaux.
- Ouverture de l’éditeur natif ; les copies sont enregistrées ou abandonnées avec le formulaire.
- Bouton accessible, traductions françaises et anglaises, navigation AJAX et protection contre les doubles clics.
- Contrôles d’accès, propriété du brouillon, verrouillage et CSRF ; aucune modification du cœur ni migration.

## Compatibilité et limites

Cible validée : **Mautic 6.0.9**, PHP **8.1, 8.2 et 8.3**. Le paquet limite l’installation à Mautic `>=6.0.9 <6.1` et PHP `>=8.1 <8.5` ; ces contraintes ne certifient pas les versions intermédiaires non testées. Consulter les rapports [fonctionnel](https://github.com/WebAnyOne/mautic-form-field-duplicator/blob/v1.0.0/docs/VALIDATION.md) et [de préparation de release](https://github.com/WebAnyOne/mautic-form-field-duplicator/blob/v1.0.0/docs/RELEASE_VALIDATION.md).

18 types natifs sont pris en charge. Les boutons, CAPTCHA, champs sociaux, sauts de page et types tiers sont exclus. Les références écrites librement dans du HTML, CSS ou JavaScript doivent être vérifiées après duplication. Un seul onglet par formulaire enregistré est recommandé en raison du brouillon partagé de Mautic 6.0.9.

## Installation

Télécharger **WebAnyOneFormFieldDuplicatorBundle-1.0.0.zip** et **WebAnyOneFormFieldDuplicatorBundle-1.0.0.zip.sha256**. Vérifier le fichier :

```sh
shasum -a 256 -c WebAnyOneFormFieldDuplicatorBundle-1.0.0.zip.sha256
```

Depuis la racine Mautic, avec le PHP et l’utilisateur de cette installation :

```sh
unzip WebAnyOneFormFieldDuplicatorBundle-1.0.0.zip -d plugins/
php bin/console cache:clear --env=prod
php bin/console mautic:plugins:reload --env=prod
php bin/console mautic:assets:generate --env=prod
```

Publier ensuite **WebAnyOne Form Field Duplicator** dans **Paramètres → Plugins**, puis recharger complètement l’administration. Le ZIP possède directement le dossier `WebAnyOneFormFieldDuplicatorBundle/`. Les archives automatiques « Source code » de GitHub ne conviennent pas à cette installation.

Le [README](https://github.com/WebAnyOne/mautic-form-field-duplicator/blob/v1.0.0/README.md) décrit l’installation Composer, l’utilisation et la désinstallation. Les champs déjà enregistrés et les soumissions restent disponibles après retrait du plugin.
