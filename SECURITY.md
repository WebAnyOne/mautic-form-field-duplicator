# Sécurité

La première release est validée sur Mautic 6.0.9. Les autres versions doivent être testées avant utilisation. Les contrôles du plugin concernent ses propres routes ; ils ne changent pas les autorisations ou opérations des gestionnaires natifs de Mautic.

Pour signaler une vulnérabilité, utiliser **Security → Report a vulnerability** dans le dépôt GitHub lorsque cette fonctionnalité est disponible. À défaut, demander un canal de contact privé dans une issue, sans publier de preuve d’exploitation ni de données sensibles. Le propriétaire du dépôt doit activer les signalements privés dans ses paramètres avant publication.

Les rapports doivent préciser les versions Mautic/PHP, les étapes de reproduction sur une instance de test et le résultat attendu. Ne pas joindre de configurations complètes, identifiants, tokens, journaux contenant des données personnelles ou fichiers clients.
